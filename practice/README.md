# 练习与课堂示例

本目录集中存放近期课堂/练习用的零散脚本与配套数据，避免堆在仓库根目录。

| 文件 | 说明 |
|------|------|
| `Clock.py` | 终端彩色时钟 |
| `SystemTimerWidget.py` | PySide6 桌面时间挂件（含倒计时） |
| `funs.py` / `funs_son_dir/` / `funs_call_demo_same_dir.py` | 函数与跨目录导入示例 |
| `def_demo.py` / `demo.py` / `tup.py` / `path.py` / `ip.py` | 语法小练习 |
| `闰年*.py` / `leap_years.csv` | 闰年相关练习 |
| `salary.py` / `xlrd_demo.py` / `有问题的薪资.*` / `工资表.xls` | Excel 读取与薪资解析练习 |

在本目录下运行脚本时，相对路径（如 Excel 文件名）可保持不变。
