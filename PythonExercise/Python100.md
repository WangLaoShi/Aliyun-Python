## 实例 001：数字组合

题目 有四个数字：1、2、3、4，能组成多少个互不相同且无重复数字的三位数？各是多少？

程序分析 遍历全部可能，把有重复的剃掉。

```python
# 方法一：使用三重循环遍历所有可能的组合
total = 0  # 初始化计数器，用于统计符合条件的三位数个数

# 第一层循环：遍历百位数字（1-4）
for i in range(1, 5):
    # 第二层循环：遍历十位数字（1-4）
    for j in range(1, 5):
        # 第三层循环：遍历个位数字（1-4）
        for k in range(1, 5):
            # 判断三个数字是否互不相同（无重复）
            if ((i != j) and (j != k) and (k != i)):
                print(i, j, k)  # 打印符合条件的三位数
                total += 1      # 计数器加1
print(total)  # 输出总个数

# 方法二：使用itertools模块的permutations函数（更简便的方法）
import itertools  # 导入itertools模块，用于排列组合

sum2 = 0  # 初始化计数器
a = [1, 2, 3, 4]  # 定义数字列表

# 使用permutations生成所有3个数字的排列
for i in itertools.permutations(a, 3):
    print(i)  # 打印每个排列
    sum2 += 1  # 计数器加1
print(sum2)  # 输出总个数
```

## 实例 002："个税计算"

题目 企业发放的奖金根据利润提成。利润(I)低于或等于10万元时，奖金可提10%；利润高于10万元，低于20万元时，低于10万元的部分按10%提成，高于10万元的部分，可提成7.5%；20万到40万之间时，高于20万元的部分，可提成5%；40万到60万之间时高于40万元的部分，可提成3%；60万到100万之间时，高于60万元的部分，可提成1.5%，高于100万元时，超过100万元的部分按1%提成，从键盘输入当月利润I，求应发放奖金总数？

程序分析 分区间计算即可。

```python
# 从用户输入获取当月利润
profit = int(input('Show me the money: '))

# 初始化奖金总额
bonus = 0

# 定义各档次的利润阈值（单位：元）
# 对应关系：10万以下、10-20万、20-40万、40-60万、60-100万、100万以上
thresholds = [100000, 100000, 200000, 200000, 400000]

# 定义各档次的提成比例
# 对应关系：10%、7.5%、5%、3%、1.5%、1%
rates = [0.1, 0.075, 0.05, 0.03, 0.015, 0.01]

# 遍历各个利润档次进行计算
for i in range(len(thresholds)):
    # 如果当前利润小于等于当前档次的阈值
    if profit <= thresholds[i]:
        # 按当前档次的提成比例计算奖金
        bonus += profit * rates[i]
        # 利润已全部计算完毕，清零并跳出循环
        profit = 0
        break
    else:
        # 当前档次的利润按对应比例计算
        bonus += thresholds[i] * rates[i]
        # 减去已计算的利润部分
        profit -= thresholds[i]

# 处理剩余利润（超过100万的部分按1%计算）
bonus += profit * rates[-1]

# 输出最终奖金总额
print(bonus)
```

## 实例 003：完全平方数

题目 一个整数，它加上100后是一个完全平方数，再加上168又是一个完全平方数，请问该数是多少？

程序分析 因为168对于指数爆炸来说实在太小了，所以可以直接省略数学分析，用最朴素的方法来获取上限:

```python
# 方法一：确定搜索上限
n = 0
# 寻找满足条件的上限：当(n+1)² - n² <= 168时继续
# 这是因为如果两个完全平方数相差168，那么它们的平方根之差不会太大
while (n + 1) ** 2 - n * n <= 168:
    n += 1
print(n + 1)  # 输出上限值
```

思路是：最坏的结果是n的平方与(n+1)的平方刚好差168，由于是平方的关系，不可能存在比这更大的间隙。

至于判断是否是完全平方数，最简单的方法是：平方根的值小数为0即可。

结合起来：

```python
# 方法二：完整的解决方案
n = 0
# 确定搜索上限
while (n + 1) ** 2 - n * n <= 168:
    n += 1

# 在上限范围内搜索满足条件的数
for i in range((n + 1) ** 2):
    # 判断i+100是否为完全平方数：平方根为整数
    # 判断i+100+168是否为完全平方数：平方根为整数
    if i ** 0.5 == int(i ** 0.5) and (i + 168) ** 0.5 == int((i + 168) ** 0.5):
        print(i - 100)  # 输出原数（减去100得到答案）
```

## 实例 004：这天第几天

题目 输入某年某月某日，判断这一天是这一年的第几天？

程序分析 特殊情况，闰年时需考虑二月多加一天：

```python
# 定义判断闰年的函数
def isLeapYear(y):
    # 闰年规则：能被400整除，或者能被4整除但不能被100整除
    return (y % 400 == 0 or (y % 4 == 0 and y % 100 != 0))

# 定义每月天数数组（非闰年）
# 索引0对应1月，索引1对应2月，以此类推
DofM = [0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30]

# 初始化结果变量
res = 0

# 获取用户输入的年、月、日
year = int(input('Year:'))
month = int(input('Month:'))
day = int(input('day:'))

# 如果是闰年，将2月的天数改为29天
if isLeapYear(year):
    DofM[2] += 1

# 计算该日期是当年的第几天
# 累加该月之前所有月份的天数
for i in range(month):
    res += DofM[i]

# 加上当月的天数
print(res + day)
```

## 实例 005：三数排序

题目 输入三个整数x,y,z，请把这三个数由小到大输出。

程序分析 练练手就随便找个排序算法实现一下，偷懒就直接调函数。

```python
# 方法一：使用冒泡排序算法
raw = []  # 创建空列表存储输入的数字

# 循环输入三个整数
for i in range(3):
    x = int(input('int%d: ' % (i)))  # 获取用户输入并转换为整数
    raw.append(x)  # 将输入的数字添加到列表中

# 冒泡排序：比较相邻元素并交换
for i in range(len(raw)):
    for j in range(i, len(raw)):
        # 如果前面的数大于后面的数，则交换位置
        if raw[i] > raw[j]:
            raw[i], raw[j] = raw[j], raw[i]  # Python的多重赋值语法

print(raw)  # 输出排序后的列表

# 方法二：使用Python内置的sorted函数（更简便）
raw2 = []  # 创建新的空列表

# 循环输入三个整数
for i in range(3):
    x = int(input('int%d: ' % (i)))  # 获取用户输入
    raw2.append(x)  # 添加到列表

print(sorted(raw2))  # 使用sorted函数排序并输出
```

## 实例 006：斐波那契数列

题目 斐波那契数列。

程序分析 斐波那契数列（Fibonacci sequence），从1,1开始，后面每一项等于前面两项之和。图方便就递归实现，图性能就用循环。

```python
# 方法一：递归实现（简洁但效率较低）
def Fib(n):
    # 递归终止条件：前两项都是1
    if n <= 2:
        return 1
    else:
        # 递归公式：F(n) = F(n-1) + F(n-2)
        return Fib(n - 1) + Fib(n - 2)

# 获取用户输入并计算斐波那契数列的第n项
print(Fib(int(input())))

# 方法二：迭代实现（效率更高）
target = int(input())  # 获取用户输入的目标项数
res = 0  # 初始化结果变量（实际未使用）

# 初始化前两项
a, b = 1, 1  # a和b分别代表F(n-2)和F(n-1)

# 循环计算到第target项
for i in range(target - 1):
    # 更新a和b：a变为b，b变为a+b
    a, b = b, a + b

print(a)  # 输出第target项的值
```

## 实例 007：copy

题目 将一个列表的数据复制到另一个列表中。

程序分析 使用列表[:]，拿不准可以调用copy模块。

```python
import copy  # 导入copy模块，用于深拷贝操作

# 创建一个包含嵌套列表的原始列表
a = [1, 2, 3, 4, ['a', 'b']]

# 方法一：直接赋值（引用复制）
b = a  # b和a指向同一个对象，修改a会影响b

# 方法二：浅拷贝（使用切片）
c = a[:]  # 创建a的浅拷贝，只复制第一层

# 方法三：使用copy.copy()进行浅拷贝
d = copy.copy(a)  # 与切片效果相同

# 方法四：深拷贝（使用copy.deepcopy()）
e = copy.deepcopy(a)  # 递归复制所有层级

# 测试各种复制方式的效果
a.append(5)  # 在a的末尾添加元素5
a[4].append('c')  # 在a的嵌套列表中添加元素'c'

# 输出各种复制方式的结果
print('a =', a)  # 原始列表
print('b =', b)  # 直接赋值：完全跟随a的变化
print('c =', c)  # 浅拷贝：第一层独立，嵌套对象共享
print('d =', d)  # 浅拷贝：与c相同
print('e =', e)  # 深拷贝：完全独立，不受a的影响

# 输出结果说明：
```

## 实例 019：完数

题目 一个数如果恰好等于它的因子之和，这个数就称为"完数"。例如6=1＋2＋3.编程找出1000以内的所有完数。

程序分析 将每一对因子加进集合，在这个过程中已经自动去重。最后的结果要求不计算其本身。

```python
# 定义函数：计算一个数的所有因子
def factor(num):
    target = int(num)  # 确保输入是整数
    res = set()        # 使用集合存储因子，自动去重
    
    # 遍历从1到num-1的所有数
    for i in range(1, num):
        if num % i == 0:  # 如果i是num的因子
            res.add(i)    # 添加因子i
            res.add(num / i)  # 添加对应的另一个因子
    
    return res  # 返回因子集合

# 遍历2到1000的所有数，寻找完数
for i in range(2, 1001):
    # 判断i是否为完数：i等于其所有因子之和减去i本身
    # 因为factor函数包含了i本身，所以需要减去
    if i == sum(factor(i)) - i:
        print(i)  # 输出完数
```

## 实例 065：画组合图形

题目 一个最优美的图案。

程序分析 无。

```python
import math  # 导入数学模块
from tkinter import *  # 导入tkinter模块

# 定义点类，用于存储坐标
class PTS:
    def __init__(self):
        self.x = 0  # x坐标
        self.y = 0  # y坐标

# 存储所有点的列表
points = []

# 定义绘制函数
def LineToDemo():
    # 设置屏幕尺寸
    screenx = 400
    screeny = 400
    
    # 创建画布
    canvas = Canvas(width=screenx, height=screeny, bg='white')
    
    # 设置长宽比
    AspectRatio = 0.85
    MAXPTS = 15  # 最大点数
    
    # 获取画布尺寸
    h = screeny
    w = screenx
    
    # 计算中心点坐标
    xcenter = w / 2
    ycenter = h / 2
    
    # 计算半径
    radius = (h - 30) / (AspectRatio * 2) - 20
    
    # 计算角度步长
    step = 360 / MAXPTS
    angle = 0.0
    
    # 生成所有点的坐标
    for i in range(MAXPTS):
        # 将角度转换为弧度
        rads = angle * math.pi / 180.0
        
        # 创建点对象
        p = PTS()
        # 计算x坐标
        p.x = xcenter + int(math.cos(rads) * radius)
        # 计算y坐标（考虑长宽比）
        p.y = ycenter - int(math.sin(rads) * radius * AspectRatio)
        
        # 更新角度
        angle += step
        # 将点添加到列表
        points.append(p)
    
    # 绘制外圆
    canvas.create_oval(xcenter - radius, ycenter - radius,
                       xcenter + radius, ycenter + radius)
    
    # 绘制所有点之间的连线
    for i in range(MAXPTS):
        for j in range(i, MAXPTS):
            # 连接点i和点j
            canvas.create_line(points[i].x, points[i].y, points[j].x, points[j].y)
    
    # 将画布添加到窗口
    canvas.pack()
    
    # 启动主循环
    mainloop()

# 主程序入口
if __name__ == '__main__':
    LineToDemo()
```

```python
# 定义方程：x² + 2x + 1 = 0
def equation(x):
    return x**2 + 2*x + 1

# 使用二分法求解方程
left, right = -10, 10  # 设置搜索区间
while right - left > 1e-6:  # 当区间足够小时停止
    mid = (left + right) / 2  # 计算中点
    if equation(mid) > 0:  # 如果中点函数值大于0
        right = mid  # 在左半区间继续搜索
    else:
        left = mid  # 在右半区间继续搜索

# 输出方程的解
print(left)
```
